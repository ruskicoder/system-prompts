# Tool Defaults

- `js-reverse_list_network_requests`: look at the default first page of results first; page further only if needed
- `js-reverse_search_in_sources`: `excludeMinified=true` by default
- `js-reverse_get_script_source`: read only small fragments; for a whole source file prefer `js-reverse_save_script_source`
- `js-reverse_break_on_xhr`: give only URL fragments that hit reliably
- `js-reverse_get_paused_info`: look at `frameIndex=0` first by default
